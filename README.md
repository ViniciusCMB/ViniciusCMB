## About

I build embedded systems and mission-critical software for rockets and satellites. The stack runs from ESP32 firmware in a PocketQube spinning through air, down LoRa telemetry links, to a ground-station WebUI and the pipeline that turns raw CSV into certified motor reports.

Day to day: **C/C++ on ESP32**, **Python**, **Laravel/PHP**, and **BI tools (Spotfire, Power BI)**. I'm also on the **RocketPy-Team LibDev** — the open-source 6-DOF trajectory simulator used in competitions like EuRoC and LASC.

## Current Missions

### Flight Computer — Missions Dédalo (1 km) & Thonyan (500 m)

OOP firmware on ESP32 with a 4-state FSM for flight phases. Validated against real flight data from LASC. Includes KiCad electronics, bench testing, FMECA analysis.

> [`flight-computer`](https://github.com/ViniciusCMB/flight-computer) · [`flight-simulations`](https://github.com/ViniciusCMB/flight-simulations)

### Helike — PocketQube 1P (LASC 2026)

ESP32-C3 satellite with bioinspired autorotating recovery (SRAB, maple-seed dynamics), LoRa triangulation with 3 ground beacons. Firmware, KiCad hardware, analysis notebooks.

> [`satellite`](https://github.com/ViniciusCMB/satellite) · [`recovery-webui`](https://github.com/ViniciusCMB/recovery-webui)

### Static Fire Testing Pipeline

Thrust stand (ESP32 + HX711 load cell) → CSV → Flask analysis app → Simpson integration for impulse, NAR/TRA motor classification, PDF reports.

> [`thrust-stand`](https://github.com/ViniciusCMB/thrust-stand) · [`analysis`](https://github.com/ViniciusCMB/analysis)

### RocketPy LibDev Team

Contributing to [RocketPy](https://github.com/RocketPy-Team/RocketPy) — core library dev, flight simulations.
